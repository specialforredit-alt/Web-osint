# Web OSINT

Мобильная веб-панель для первичного анализа открытых источников. Проект использует обычные HTML, CSS и JavaScript — без npm, Python и установки библиотек.

## Функции
- IP Lookup через публичный API ipwho.is: страна, регион, провайдер, ASN и приблизительная геолокация.
- Domain Intel: DNS-записи через Cloudflare DNS over HTTPS, ссылки на RDAP и Certificate Transparency.
- Username Search: публичные поисковые ссылки по нику и проверка открытого профиля GitHub.\n- Telegram Search: поиск публичных страниц t.me, каналов/групп через веб-поиск и внешние каталоги TGStat/Telemetr.\n- Social Search: публичный поиск по Instagram, Facebook, TikTok, X, LinkedIn, VK и Reddit.
- Поиск по имени, email и телефону через публичные поисковики.
- Каталог источников и локальное сохранение дел в localStorage браузера.
- Адаптивный интерфейс для мобильных устройств.

## Публикация через GitHub Pages
1. Открой Settings → Pages.
2. В разделе Build and deployment выбери Deploy from a branch.
3. Выбери ветку main и папку /(root), затем сохрани.
4. Дождись публикации. Адрес обычно выглядит как https://<username>.github.io/Web-osint/.

## Ограничения и безопасность
- Это статический фронтенд, не сервер и не общая база данных.
- Сохранённые дела остаются в локальном хранилище текущего браузера.
- Внешние API могут иметь лимиты, временно не работать или менять условия.
- Не добавляй API-ключи или пароли в клиентский JavaScript или публичный репозиторий.
- Поиск по имени, нику, Telegram, соцсетям, email и телефону открывает поисковые ссылки; он не гарантирует автоматический сбор результатов сторонних сайтов.
- Геолокация IP приблизительна и не раскрывает точный адрес человека. Совпадения не подтверждают личность.
- Используй законно доступные публичные данные и соблюдай условия внешних сервисов.
